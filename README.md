# Daily Jobs

Successive iterations of the Daily Jobs project are preserved in `_v1_daily-jobs` through `_v5_daily-jobs`. Each version contains its own documentation and setup instructions. `jev` contains an additional jobs exploration tool.

The repository retains the original Git histories for versions 1 through 4. Those histories began independently, even though the product evolved across versions. Version 5 was first committed as part of this consolidation.
